# AI/AR Content Moderation Platform

Локальная платформа модерации изображений на TypeScript. Структура следует ТЗ: монорепозиторий pnpm, NestJS API и Worker, Next.js frontend, PostgreSQL/Prisma, Redis, MinIO.

## Быстрый запуск

1. Скопируйте `.env.example` в `.env`, замените локальные пароли, выполните `openssl rand -hex 32` и вставьте результат в `UPLOAD_API_KEY`.
2. Запустите `docker compose up --build -d`.
3. Откройте веб-приложение на `http://localhost:3000`, health endpoint API — `http://localhost:4000/health`, консоль MinIO — `http://localhost:9001`.

`docker compose down` сохраняет данные в named volumes. Для полного удаления данных используйте `docker compose down -v`.

## Загрузка

Веб-форма принимает JPEG, PNG и WebP. API проверяет сигнатуру, MIME type, размер файла, декодируемость, число кадров и разрешение, считает SHA-256, сохраняет оригинал приватно в MinIO и ставит задачу в BullMQ. Worker извлекает метаданные через ExifTool без открытия найденных URL, затем обращается к Nemotron 3.5 Content Safety и Qwen3.6 Flash через OpenRouter. Результат, объяснения, этапы выполнения, токены и фактическая стоимость сохраняются в PostgreSQL; страница загрузки показывает решение и баллы после обновления статуса.

`UPLOAD_API_KEY` хранится только на сервере и передаётся из Next.js proxy в API; браузер не получает ключ. Без заданного ключа загрузка отключена. Идентификатор приложения задаётся в форме. API статуса: `GET /api/v1/moderations/:id`.

Риск NSFW и несоответствие интерьерной тематике рассчитываются отдельно. Модельные ответы проверяются перед использованием; ошибочный ответ или ошибка API не могут дать `allow`. Критический сигнал Nemotron о сексуальном содержимом с несовершеннолетними останавливает обычный конвейер и получает решение `CRITICAL_REVIEW`.

## OpenRouter и риск-оценка

Для реального анализа задайте `OPENROUTER_API_KEY` в `.env`. Идентификаторы моделей, URL OpenRouter и начальные пороги/веса риск-оценки настраиваются через переменные `OPENROUTER_*` и `RISK_*` в `.env.example`. Стоимость берётся из usage ответа OpenRouter, фиксированные тарифы в приложении не заданы.

Если ключ отсутствует, задача завершится ошибкой, а не безопасным решением. Для локальных тестов можно явно установить `MODERATION_TEST_MODE=true`; этот режим возвращает тестовые ответы и не вызывает внешнюю модель. Не включайте его для реальной модерации.

## Панель администратора

Создайте `ADMIN_SESSION_SECRET` командой `openssl rand -hex 32` и настройте `ADMIN_USERS_JSON` как JSON-массив учётных записей с полями `id`, `password` (не менее 12 символов) и ролью `ADMIN` либо `SPECIALIST`. Используйте отдельный пароль для каждого сотрудника. Вход доступен по `/admin/login`; сессия подписана HMAC, хранится в HttpOnly cookie и истекает через 8 часов. Для `CRITICAL_REVIEW` доступ к изображению и ручному решению есть только у `SPECIALIST`.

В панели доступны показатели, история с поиском и пагинацией, карточки с метаданными и выводами моделей, захват задачи в работу, ручное одобрение/отклонение с причиной и журнал аудита. Решение записывается транзакционно и не перезаписывает исходный автоматический результат.

MinIO собирается из закреплённых исходников Community-релиза, поскольку готовый публичный образ недоступен. Bucket приватный, данные хранятся в named volume.

Не коммитьте `.env`, API ключи и другие секреты.
